# Домашнее задание № 3

Статический анализ банковского TCP-сервера с помощью Semgrep

## Цель

Выполнить статический анализ `main.py`, разобрать срабатывания и сформулировать рекомендации по устранению выявленных проблем.

## Среда и ход работы

- ОС: Windows 10.
- Анализатор: Semgrep 1.182.1, движок OSS.
- Правила: реестровый набор `p/python` + локальное правило `python.lang.security.audit.md5-used-as-password` из репозитория `semgrep-rules`.
- Объект: `main.py` (банковский TCP-сервер).
- По сводке консоли выполнено 151 правило, проверен 1 файл.
- В JSON отсутствуют ошибки сканирования; получено 6 срабатываний.

```bash
semgrep --config p/python \
        --config semgrep-rules/python/lang/security/audit/md5-used-as-password.yaml \
        --json --output=semgrep-report.json main.py
```

Проверка выполнялась без запуска сервера. Файлы клиента (`bank_client.py`) и демонстрационных атак (`attack_*.py`) не входили в область анализа.

## Результаты

В таблице приведены короткие имена правил; общий префикс идентификаторов: `python.lang.`. Для правил MD5 раздел — `security` (для `md5-used-as-password` — `security.audit`), для `arbitrary-sleep` — `best-practice`.

| № | Строка | Правило | Уровень | Анализ | Рекомендация |
|---|---|---|---|---|---|
| 1 | 38 | insecure-hash-algorithm-md5 | WARNING | MD5 при создании хеша пароля администратора (`hashlib.md5(b"admin123")`). Быстрый алгоритм упрощает перебор паролей. | Использовать `hashlib.scrypt` с индивидуальной случайной солью. |
| 2 | 41 | insecure-hash-algorithm-md5 | WARNING | MD5 при создании хеша пароля alice (`hashlib.md5(b"qwerty")`). Проблема подтверждается просмотром кода. | Использовать `hashlib.scrypt` с индивидуальной случайной солью. |
| 3 | 44 | insecure-hash-algorithm-md5 | WARNING | MD5 при создании хеша пароля bob (`hashlib.md5(b"12345")`). Проблема подтверждается просмотром кода. | Использовать `hashlib.scrypt` с индивидуальной случайной солью. |
| 4 | 142 | arbitrary-sleep | ERROR | `time.sleep(0.05)` задерживает перевод. При отсутствии блокировки увеличивает окно гонки (TOCTOU) между чтением баланса и его использованием. | Удалить задержку; защитить проверку и изменение балансов одной блокировкой или транзакцией БД. |
| 5 | 203 | insecure-hash-algorithm-md5 | WARNING | MD5 при вычислении хеша введённого пароля во время входа (`hashlib.md5(req.password.encode())`). | Перевести создание и проверку хешей на `hashlib.scrypt` с солью. |
| 6 | 203 | md5-used-as-password | WARNING | MD5 используется именно для пароля. Пересекается со срабатыванием № 5 на той же операции. | Исправляется вместе со срабатыванием № 5. |

## Вывод

В результате статического анализа файла `main.py` инструментом Semgrep версии 1.182.1 получено шесть срабатываний по трём правилам: пять уровня WARNING и одно уровня ERROR. Обнаружено использование MD5 при создании и проверке хешей паролей, а также искусственная задержка в функции перевода денежных средств. Два срабатывания на строке 203 относятся к одной операции. Рекомендуется заменить MD5 специализированным алгоритмом хеширования паролей с индивидуальной солью (`hashlib.scrypt`) и обеспечить атомарность операций с балансами. Проверка завершилась без ошибок. Отсутствие других срабатываний не подтверждает безопасность приложения: статический анализ необходимо дополнять ручной проверкой и функциональными испытаниями.
