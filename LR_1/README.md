# Результаты применения запросов

| Запрос | Тело | Что делает | Ответ сервера | Пример вывода |
|--------|------|-----------|---------------|---------------|
| `GET /users` | — | Список всех пользователей | `200 OK` + JSON со всеми тремя пользователями | `200 OK` — `{"user1": {"name": "Алексей", ...}, "user2": {"name": "Мария", ...}, "user3": {"name": "Игорь", ...}}` |
| `GET /users/user2` | — | Данные конкретного пользователя | `200 OK` + `{"name": "Мария", ...}` | `200 OK` — `{"name": "Мария", "game": "Valorant", "level": 30, "score": 9870, "playtime_hours": 95}` |
| `POST /users/user1/score` | `{"score": 500}` | Начисление очков | `200 OK`, `score` стал `15820` (было `15320`) | `200 OK` — `{"name": "Алексей", "game": "Dota 2", "level": 42, "score": 15820, "playtime_hours": 210}` |
| `GET /users/user99` | — | Несуществующий пользователь | `404` + `{"error": "Пользователь не найден"}` | `404 Not Found` — `{"error": "Пользователь не найден"}` |
| `POST /users/user1/score` | — (пусто) | Пустое тело запроса | `400` + `{"error": "Тело запроса пустое"}` | `400 Bad Request` — `{"error": "Тело запроса пустое"}` |
| `POST /users/user1/score` | `{"score": "abc"}` | Неверный тип данных | `400` + `{"error": "Поле score должно быть числом"}` | `400 Bad Request` — `{"error": "Поле score должно быть числом"}` |
| `GET /foo` | — | Несуществующий маршрут | `404` + `{"error": "Маршрут не найден"}` | `404 Not Found` — `{"error": "Маршрут не найден"}` |
| `DELETE /users` | — | Неподдерживаемый метод | `405` + `{"error": "Метод не поддерживается"}` | `405 Method Not Allowed` — `{"error": "Метод не поддерживается"}` |
